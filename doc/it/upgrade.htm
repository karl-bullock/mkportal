Aggiornamento a MKPortal C1.2

STEP 1: Controlla i requisiti, Versione di MKP & Board compatibili

Requisiti minimi:

  • Piattaforme: Linux, Windows, FreeBSD, OS X, Sun
  • Spazio: L'installazione di default di MKPortal richiede approssimamente 5 MB di spazio nel webserver. Ciò non include i file del forum , skin aggiuntive e altri add-ons, oppure i file uploadati dagli utenti nei moduli Gallery, Download, Blog o TopSite. Probabilmente avrai bisogno di almeno 8-10 mb di spazio per una community di moderate dimensioni che usa tutti questi moduli.
  • PHP: PHP 4.1.0 o superiore. Nota: Verificare anche i requisiti minimi della board che possono essere differenti dai requisiti minimi di MKPortal.
  • MySQL: 3.23.4 o superiore (4.1 con phpBB3). Nota: Verificare anche i requisiti minimi della board che possono essere differenti dai requisiti minimi di MKPortal.
  • Database: 1 database MySQL con almeno 500 KB di spazio per le tabelle del portale. L'installazione di default di MKPortal condivide il database del forum e richiede approssimatamente 280 KB di spazio nel database oltre allo spazio usato dalle tabelle del database del forum. Ovviamente avrai bisogno di molto più spazio nel database per una Community attiva.
  • GD Graphics Library versione 1.0 o superiore. Le GD library sono necessarie per la funzione watermark della Gallery e per la creazione delle anteprime.

Nota importante per gli utenti di phpBB3: L'Integrazione di phpBB3 con MKPortal necessita di ulteriori requisiti :

  • MySQL: 4.1 o superiore. La collocazione delle tabelle del database deve essere UTF-8.
  • File di lingua: I file di lingua di MKPortal devono essere in UTF-8.

Versioni di MKPortal Compatibili:

  • MKPortal M1.0 o superiore è richiesto per questo aggiornamento.
  • La cartella "upgrades" include 2 script di aggiornamento aggiuntivi per incrementare l'aggiornamento da M08 a M09 o da M09 a M1.0. Questi devono essere lanciati ( in ordine di versione ) prima di lanciare "upgrades/index.php" se stai aggiornando da M08 o M09.
  • Se hai bisogno di aggiornare una versione più vecchia di M08 per favore visita il forum di supporto per assistenza.

Board Compatibili:

Questa versione di MKPortal è compatibile con le seguenti board:

  • SMF 1.1.x
  • IPB 1.3.x
  • IPB 2.3.x
  • vB 3.7.x
  • phpBB 2.0.x
  • phpBB 3.x
  • MyBB 1.2.x
  • AEF 1.0.6

STEP 2: Backup File & Database

Prima di aggiornare è importante fare un backup dei file di MKPortal e del database (inclusa la vostra Board).

STEP 3: Cartelle & File deprecati

È importante per motivi di sicurezza cancellare file e cartelle inutilizzate.

M1.0 o versioni precedenti: Se stai aggiornando dalla M1.0 è importante eliminare la cartella "mkportal/include" prima di aggiornare i nuovi file. La struttura delle cartelle è cambata dopo M1.0

Tutte le versioni: Eliminare i seguenti file dal webserver se esistono. Questi file sono stati rinominati, eliminati o spostati.

  • mkportal/include/pmpopup.php
  • mkportal/admin.php
  • mkportal/modules/blog/disclaimer.txt

STEP 4: Upload dei nuovi File di MKPortal & Cartelle

Caricare i nuovi file di MKPortal contenuti in questo pacchetto nel tuo webserver sovrascrivendo tutti i vecchi file ECCETTO i seguenti:

  • mkportal/conf_mk.php (File di configurazione di MKPortal)
  • lang/*/lang_blocktitle.php (Titoli personali dei blocchi per tutte le lingue)
  • mkportal/modules/gallery/wt.png (Immagine Watermark utilizzata nella MKPGallery)
  • aeforum/universal.php (File di configurazione di AEF, in caso utilizziate la board interna)

Ovviamente se hai modificato il tuo template o altri file devi aggiungere le modifiche ai nuovi file.

STEP 5: CHMOD dei File di MKPortal & delle Cartelle

Dovrete impostare i permessi ai seguenti files (0666) e cartelle (0777) incluso i contenuti:

  • mkportal/conf_mk.php
  • mkportal/blog
  • mkportal/blog/images
  • mkportal/blog/images/tmp
  • mkportal/cache
  • mkportal/lang
  • mkportal/lang/English
  • mkportal/lang/Francais
  • mkportal/lang/Italiano
  • mkportal/modules/downloads/file
  • mkportal/modules/gallery/album
  • mkportal/modules/gallery/album/tmp
  • mkportal/modules/reviews/images
  • mkportal/modules/reviews/images/tmp
  • mkportal/templates
  • mkportal/templates/default
  • mkportal/templates/Forum

STEP 6: Aggiornamento di MKPortal

Avviate lo script di aggiornamento digitando http://www.example.com/mkportal/upgrades/index.php. L'aggiornamento guidato vi aiuterà ad aggiornare le tabelle nel database di MKPortal.

STEP 7: Eliminazione dei i file di Installazione e Upgrade di MKPortal

Molto importante per la vostra sicurezza! Cancellare Immediatamente il file mk_install.php e la cartella mkportal/upgrades del vostro spazio dopo la completa installazione. In caso vi dimentichiate un messaggio nell'amministrazione ve lo ricorderà fino alla loro eliminazione.

Solo per gli utenti AEF: Cancellare immediatamente le cartelle aeforum/setup e aeforum/upgrade dal server per motivi di sicurezza.

Aggiornamento Completato. Grazie per aver scelto MKPortal e buon Divertimento!

STEP 8 [Opzionale] : Modifica dei File della Board

Potrebbe essere necessario ri-modificare i file del forum. È consigliabile iniziare dai file di default e aggiungere le modifiche ai file della board.

Se volete visualizzare la Board all'interno di MKPortal, selezionate la vostra qua sotto per le specifiche istruzioni.

Potrebbe anche essere necessario modificare i file della board se vuoi mettere il forum offline mantenendoil portale online.
