Mise à jour vers MKPortal C1.2

ETAPE 1: Vérifier les requis systèmes, les versions MKP et compatibilités des forums.

Configurations minimales:

  • Platformes: Linux, Windows, FreeBSD, OS X, Sun
  • Espace disque: L'installation par défaut de MKPortal nécessite environ 5 MB d'espace disque sur le serveur web. Ceci n'inclut pas les fichiers propres au forum, les skins additionnels du portail et autres ajouts ou fichiers supplémentaires des utilisateurs dans les galleries, sections de téléchargements, Albums des blogs ou section "TopSites". Vous aurez probablement besoin d'au moins 8 à 10 MB d'espace disque pour un portail de taille moyenne utilisant tous ces modules.
  • PHP: PHP 4.1.0 ou supérieur. Note: Vous devrez aussi vous assurer que les minimums requis pour le script de votre forum sont atteints (ils sont différents de ceux attendus pour MKPortal). 
  • MySQL: 3.23.4 or suppérieur. Note: Vous devrez aussi vous assurer que les minimums requis pour le script de votre forum sont atteints (ils sont différents de ceux attendus pour MKPortal). 
  • Base de Données: 1 base MySQL avec au moins 500 KB d'expace de stockage pour les tables de la base de données du portail. L'installation par défaut de MKPortal partage la base de données du forum et nécessite approximativement 280 KB d'espace de stockage supplémentaire à celui utilisé par les tables de la base du forum. Bien sûr vous aurez besoin de beaucoup plus d'espace de stockage pour une base de données d'une communauté active.
  • GD: La version 1.0 de Bibliothèque Graphique ou supérieure. La bibliothèque GD est nécessaire pour la fonction de filigrane de la Galerie et la génération des miniatures.

Important note for phpBB3 users: The MKPortal phpBB3 integration has additional requirements:

  • MySQL: 4.1 or suppérieur. Database table collation must also be UTF-8.
  • Language files: MKPortal language files must be UTF-8

Compatibilité de version MKPortal:

  • MKPortal M1.0 ou version supérieure est nécessaire pour cette mise à jour. 
  • Le répertoire "upgrades" contient deux scripts de mise à jour additionnels pour évoluer progressivement des versions M08 à M09 ou M09 à M1.0. Ceux-ci doivent être exécutés (par ordre de numéro de version) avant le lancement de  "upgrades/index.php" si vous évoluez d'une version M08 ou M09.
  • Si vous devez évoluer depuis une version plus ancienne que la M08, visitez le forum de support pour obtenir de l'assistance.

Versions compatibles de forums:

Cette version de MKPortal est compatible avec les versions suivantes de forum:

  • SMF 1.1.x
  • IPB 1.3.x
  • IPB 2.3.x
  • vB 3.7.x
  • phpBB 2.0.x
  • phpBB 3.x
  • MyBB 1.2.x
  • AEF 1.0.6

ETAPE 2: Sauvegarde de Fichiers et de Base de données

Avant mise à jour, il est important que vous sauvegardiez les fichiers MKPortal de installés sur votre serveur ainsi que la base de données (incluant les tables de MKPortal et du forum).

ETAPE 3: Supprimez les anciens fichiers et répertoires

Il est important pour la sécurité de supprimer les fichiers et répertoires inutilisés.  

M1.0 ou versions supérieures: Si vous évoluez d'une version M1.0, il est important que vous détruisiez le répertoire "mkportal/include" avant l'envoi des nouveaux fichiers. La structure des répertoires a changé arpès la version M1.0. 

Toutes versions: Détruisez les fichiers suivants de votre serveur s'ils existent. Ces fichiers ont été renomés, supprimés ou déplacés. 

  • mkportal/include/pmpopup.php
  • mkportal/admin.php
  • mkportal/modules/blog/disclaimer.txt

ETAPE 4: Transférez les nouveaux fichiers et répertoires MKPortal

Transférez, sur votre serveur, les nouveaux fichiers MKPortal contenus dans ce package en écrasant les fichiers précédents A L'EXCEPTION des fichiers suivants:

  • mkportal/conf_mk.php (fichier de configuration deMKPortal)
  • lang/*/lang_blocktitle.php (Titres de Bloc Personnalisés pour tous les langages)
  • mkportal/modules/gallery/wt.png (Image de filigrane utilisée dans MKPGALLERY)
  • aeforum/universal.php (fichier de configuration de AEF)

Evidemment, vi vous avez modifié votre "template" ou d'autres fichiers, vous devrez ajouter vos modifications aux nouveaux fichiers. Et n'oubliez pas de transférer le nouveau fichier index.php principal de MKPortal. 

ETAPE 5: CHMOD sur les fichiers et répertoires MKPortal

Mettez les droits en écriture sur les fichiers suivants (CHMOD 0666) ainsi que sur les répertoires  (CHMOD 0777) en incluant leurs sous-répertoires contenu:

  • mkportal/conf_mk.php
  • mkportal/blog
  • mkportal/blog/images
  • mkportal/blog/images/tmp
  • mkportal/cache
  • mkportal/lang
  • mkportal/lang/English
  • mkportal/lang/Francais
  • mkportal/lang/Italiano
  • mkportal/modules/downloads/file
  • mkportal/modules/gallery/album
  • mkportal/modules/gallery/album/tmp
  • mkportal/modules/reviews/images
  • mkportal/modules/reviews/images/tmp
  • mkportal/templates
  • mkportal/templates/default
  • mkportal/templates/Forum

ETAPE 6: Exécutez le script de mise à jour de la base de données de MKPortal

Lancez le script de mise à jour à l'adresse suivante:  http://www.example.com/mkportal/upgrades/index.php. Suivez simplement les indications dans le script pour pour mettre à jour les tables de la base de données de MKPortal. 

ETAPE 7: Détruisez l'installeur de MKPortal et les fichiers de mise à jour.

Note importante de sécurité! Effacez immédiatement le fichier  mk_install.php ainsi que le répertoire mkportal/upgrades du serveur. Ne laissez pas le script d'installation ou ceux de mise à jour sur le serveur.

AEF users only: Immediately delete the aeforum/setup and aeforum/upgrade folders file from the server for security reasons.

La mise à jour est complète. Prenez du plaisir à utiliser MKPortal.

ETAPE 8 [Optionel] : Edition des fichiers de forums

Si vous souhaitez voir votre forum intégré à MKPortal, sélectionnez ci dessous votre type de forum pour accèder aux instructions spécifiques à celui-ci.

Puisque la modification de code pour votre forum risque d'avoir changé, vous pourriez devoir re-modifier les fichiers propres à botre forum. Il est généralement préférable de repartir à neuf et d'ajouter les modifications à vos nouveaux fichiers par défaut de forum. 

You may also need to edit board files if you want to set the forum offline while keeping the portal online.
