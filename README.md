## Notes on this conversion

Converted from the package's original `readme.htm` (dated 2008-01-07), which
was written against the C1.2 package layout. Two things differ in R1.0.2:

- **The English documentation links are dead.** The original readme linked to
  `doc/en/install.htm` and `doc/en/upgrade.htm`, but R1.0.2 ships only `fr`,
  `it` and `ru`. The English C1.2 docs are on this repository's `OG` branch
  under `doc/en/`, so they are excluded from the table above.
- **Russian is now live.** The original readme had Russian, German, Spanish,
  Dutch, Turkish and Hebrew entries commented out as placeholders. R1.0.2
  actually ships `doc/ru`, so it is listed above; the other five were never
  written and are omitted.

The `License` link points to `LICENSE` rather than the package's original
`license.txt`. See [PROVENANCE.md](PROVENANCE.md) for why.
